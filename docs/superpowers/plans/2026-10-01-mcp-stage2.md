# Embedded MCP Server Stage 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 15 MCP tools so a client can build a playlist, edit the timeline (cut, trim, move, transitions, fades), see frames, and export an MP4 end to end.

**Architecture:** The stage 1 `McpServer` and tool table stay; `mcptools.cpp` is split by area (frame, timeline, export) with shared helpers. Edits push Shotcut's own undoable commands; export goes through a new quiet `EncodeDock::exportToFile()` and the existing background job queue.

**Tech Stack:** C++17, Qt 6.10.3 (Core, Gui, Widgets, Network), MLT 7.36.1, CMake/Ninja, bash + curl + jq + ffmpeg/ffprobe for smoke tests.

**Spec:** `docs/superpowers/specs/2026-10-01-mcp-stage2-design.md` (read it first; stage 1 context in `2026-10-01-mcp-control-server-design.md` and `docs/mcp-server.md`).

## Global Constraints

- Edits go through undoable commands (`Timeline::*Command`, `Playlist::*Command`) on `MAIN.undoStack()`; never call `MultitrackModel` mutators, the drag-gesture `TimelineDock::trimClipIn/Out` overloads, or `TimelineDock::moveClip` (signal-based).
- Tools take explicit `(track, clip)` indexes or absolute frames; no dependence on selection, current track, playhead or clipboard unless the tool sets it explicitly. Every edit returns the updated track summary (same shape as a `get_timeline` `tracks[]` entry). Track 0 is the TOPMOST video track.
- No silent no-ops: locked tracks, blank/transition targets, invalid trims, overlapping moves and invalid transitions are pre-validated and return `isError`.
- No tool opens a modal dialog. The only known modal is `LongUiTask` inside `AppendCommand` (it waits for no input; the `m_busy` guard rejects other `tools/call` requests meanwhile).
- Arguments are validated strictly (integer frames >= 0, absolute paths, no `:`-prefixed resource paths, booleans are booleans).
- `get_frame` defaults: JPEG quality 80, `max_width` 640 (64-1920), PNG optional, never upscale.
- Export: `x264-medium` default preset; absolute path; extension equals the preset's `meta.preset.extension`; parent folder exists and is writable; free space at least 1 GiB; no overwrite unless `overwrite:true`; output not inside the project XML; `melt-7` present where `MeltJob` looks; one export at a time; the render runs as a background job (never inside the tool call).
- Code conventions (`AGENTS.md`): `m_` member prefix, `camelCase` methods, `PascalCase` classes, header guards `#ifndef CLASSNAME_H`, new-style `connect()` only, 4-space indent. NEW source files carry the GPLv3 notice WITHOUT a copyright line (the user does not claim copyright); existing files you modify keep their existing copyright lines untouched. ## Review Focus

Failure modes the spec implies but happy-path tests do not exercise, most likely first. Each has a named test or review point in the task that owns the code.

1. `get_frame` with a `position` returns the PREVIOUS frame (the display lags the seek) or hangs: wait for `imageReady` with a timeout; test two positions differ. (Task 2)
2. Indexes shift after split/transition/remove/lift and clients act on stale indexes: every edit returns the new track; tests assert result indexes match `get_timeline`. (Tasks 4-6)
3. Locked tracks silently do nothing in Shotcut: pre-check `isTrackLocked`; cannot be created headless, so it is a code-review point and a human check. (Tasks 4-6)
4. Export hangs on a hidden dialog (duplicate target, unwritable target, target in project) or a missing `melt-7`: error text instead; tests for existing file, unwritable dir, wrong extension, second export, unknown preset. (Task 7)
5. Edits made through tools must be one undo step each and fully reversible; `undo` also undoes the user's own GUI edits (documented). Tests undo back to the earlier state. (Tasks 4-6)
6. `playlist_add` on an empty session: Shotcut itself opens the first file to set the project profile; generators/images need a duration (refused). (Task 3)

```cpp
namespace McpTools {

QJsonObject schema(const char *json)
{
    return QJsonDocument::fromJson(json).object();
}

bool isResourcePath(const QString &path)
{
    return path.startsWith(':');
}

bool isLoaded()
{
    return MLT.producer() && MLT.producer()->is_valid();
}

FrameArg readFrame(const QJsonObject &arguments, const char *key, int &value)
{
    const QJsonValue v = arguments.value(key);
    if (v.isUndefined())
        return FrameArg::Missing;
    const double d = v.toDouble();
    if (!v.isDouble() || d != std::floor(d) || d < 0 || d > std::numeric_limits<int>::max())
        return FrameArg::Invalid;
    value = static_cast<int>(d);
    return FrameArg::Ok;
}

Mlt::Producer *timeline()
{
    return MAIN.isMultitrackValid() ? MAIN.multitrack() : nullptr;
}

int lastFrame()
{
    Mlt::Producer *tl = timeline();
    Mlt::Producer *producer = tl ? tl : MLT.producer();
    return producer ? qMax(0, producer->get_playtime() - 1) : 0;
}

void movePlayhead(int position)
{
    if (timeline())
        MAIN.seekTimeline(position);
    else
        MLT.seek(position);
}
```

- [ ] **Step 4: Implement `get_frame` in `src/mcptools_frame.cpp`** (GPLv3 notice first):

```cpp
#include "mcptools.h"
#include "mcptoolsutil.h"

#include "mainwindow.h"
#include "mltcontroller.h"
#include "videowidget.h"

#include <QBuffer>
#include <QEventLoop>
#include <QImage>
#include <QJsonDocument>
#include <QTimer>

#include <cmath>

using namespace McpTools;

namespace {

QJsonObject getFrameTool(const QJsonObject &arguments)
{
    int position = 0;
    const FrameArg positionArg = readFrame(arguments, "position", position);
    if (positionArg == FrameArg::Invalid)
        return textResult("position must be a non-negative integer frame number.", true);

    int maxWidth = 640;
    const QJsonValue maxWidthValue = arguments.value("max_width");
    if (!maxWidthValue.isUndefined()) {
        const double d = maxWidthValue.toDouble();
        if (!maxWidthValue.isDouble() || d != std::floor(d) || d < 64 || d > 1920)
            return textResult("max_width must be an integer from 64 to 1920.", true);
        maxWidth = static_cast<int>(d);
    }

    QString format = QStringLiteral("jpeg");
    const QJsonValue formatValue = arguments.value("format");
    if (!formatValue.isUndefined()) {
        format = formatValue.toString();
        if (!formatValue.isString() || (format != "jpeg" && format != "png"))
            return textResult("format must be \"jpeg\" or \"png\".", true);
    }

    if (!isLoaded())
        return textResult("Nothing is loaded.", true);
    auto *widget = qobject_cast<Mlt::VideoWidget *>(MLT.videoWidget());
    if (!widget)
        return textResult("There is no video widget to read a frame from.", true);

    if (positionArg == FrameArg::Ok) {
        // The display lags a seek, so ask for the next displayed frame and wait for it
        // (the way Shotcut's own Export Frame does); a timeout is an error, not a stale image.
        position = qMin(position, lastFrame());
        bool ready = false;
        QEventLoop loop;
        QTimer timeout;
        timeout.setSingleShot(true);
        QObject::connect(widget, &Mlt::VideoWidget::imageReady, &loop, [&]() {
            ready = true;
            loop.quit();
        });
        QObject::connect(&timeout, &QTimer::timeout, &loop, &QEventLoop::quit);
        movePlayhead(position);
        widget->requestImage();
        MLT.refreshConsumer();
        timeout.start(2000);
        loop.exec();
        if (!ready)
            return textResult("The frame was not ready in time; try again.", true);
    }

    QImage image = widget->image();
    if (image.isNull())
        return textResult("No frame is available yet.", true);

    // Frame pixels may not be square: correct to the display aspect ratio, then never upscale.
    const double dar = MLT.profile().dar();
    const int displayWidth = qRound(image.height() * dar);
    if (displayWidth > 0 && displayWidth != image.width())
        image = image.scaled(displayWidth, image.height(), Qt::IgnoreAspectRatio,
                             Qt::SmoothTransformation);
    if (image.width() > maxWidth)
        image = image.scaledToWidth(maxWidth, Qt::SmoothTransformation);

    QByteArray bytes;
    QBuffer buffer(&bytes);
```

```cpp
        return textResult("path must be an absolute file path.", true);

    if (path.endsWith(".mlt") || path.endsWith(".xml"))

    Mlt::Producer probe(MLT.profile(), path.toUtf8().constData());
    if (!probe.is_valid() || probe.get_length() <= 0)

    // profile follows it.
    Mlt::Producer *source = &probe;
    if (!isLoaded()) {

        properties.set(kShotcutSkipConvertProperty, 1);
        MAIN.open(path, &properties, false);
        if (isLoaded())
            source = MLT.producer();

    if (!producer || !producer->is_valid())

    MAIN.undoStack()->push(
```

```cpp
bool validTrack(MultitrackModel &model, int track, QString &error, bool needVideo = false)
{
    if (track < 0 || track >= model.trackList().size()) {
        error = QStringLiteral("There is no track %1; call get_timeline.").arg(track);
        return false;
    }
    if (needVideo && model.trackList().at(track).type != VideoTrackType) {

    }
    if (MAIN.timelineDock()->isTrackLocked(track)) {

    return true;
}
```

```cpp
        return textResult(error, true);
```

```cpp
        return textResult("Clips cannot move between video and audio tracks.", true);
    std::unique_ptr<Mlt::ClipInfo> info = model.getClipInfo(track, clip);
    if (!info)
        return textResult("Cannot read the clip.", true);

    const int positionDelta = toStart - info->start;
    const int trackDelta = toTrack - track;
    if (positionDelta == 0 && trackDelta == 0)
        return jsonResult(QJsonObject{{"track", trackJson(model, track)}});

    // Only free space is allowed: refuse any overlap with a clip or transition on the target track.
    const int end = toStart + info->frame_count;
    const QModelIndex targetIndex = model.index(toTrack);
    for (int c = 0; c < model.rowCount(targetIndex); ++c) {
        if ((toTrack == track && c == clip) || kindOf(model, toTrack, c) == "blank")
            continue;
        std::unique_ptr<Mlt::ClipInfo> other = model.getClipInfo(toTrack, c);
        if (other && toStart < other->start + other->frame_count && end > other->start)
            return textResult("The clip would overlap item " + QString::number(c)
                                  + " on track " + QString::number(toTrack) + ".", true);

    auto *command = new Timeline::MoveClipCommand(*dock, trackDelta, positionDelta, false);
    command->addClip(track, clip);
    MAIN.undoStack()->push(command);
    QJsonObject result{{"track", trackJson(model, toTrack)}};
    if (toTrack != track)
        result["from_track"] = trackJson(model, track);
    return jsonResult(result);
}

}
```

```cpp
    if (!MLT.producer() || !MLT.producer()->is_valid()) {

        return nullptr;
    }

        error = tr("An export is already in progress.");

    // Stock presets come from the MLT repository, custom ones from the app data folder.
    Mlt::Properties *preset = nullptr;
    const QByteArray stockKey = ("consumer/avformat/" + presetName).toLatin1();
    if (m_presets->get_data(stockKey.constData())) {
        preset = new Mlt::Properties((mlt_properties) m_presets->get_data(stockKey.constData()));
    } else {
        QDir dir(Settings.appDataLocation());
        if (dir.cd("presets") && dir.cd("encode") && QFileInfo::exists(dir.absoluteFilePath(presetName))) {
            preset = new Mlt::Properties();
            preset->load(dir.absoluteFilePath(presetName).toLatin1().constData());
        }
    }
    if (!preset || !preset->is_valid()) {
        delete preset;
        error = tr("Unknown preset: %1").arg(presetName);
        return nullptr;
    }
    const QString extension = QString::fromLatin1(preset->get("meta.preset.extension"));
    if (!extension.isEmpty() && !path.endsWith("." + extension, Qt::CaseInsensitive)) {
        delete preset;
        error = tr("The preset %1 produces .%2 files; the path must end in .%2.")
                    .arg(presetName, extension);
        return nullptr;
    }

    resetOptions();
    loadPresetFromProperties(*preset);
    delete preset;

    // Same source choice as a person would make: the timeline, else the playlist, else the clip.
    const QString wanted = MAIN.isMultitrackValid() ? "timeline"
                           : MAIN.isPlaylistValid() ? "playlist"
                                                    : "clip";
    const int index = ui->fromCombo->findData(wanted);
    if (index < 0) {
        error = tr("Cannot export from the %1 right now.").arg(wanted);
        return nullptr;
    }
    ui->fromCombo->setCurrentIndex(index);
    Mlt::Producer *service = fromProducer(true);
    if (!service || !service->is_valid()) {
        error = tr("There is nothing to export.");
        return nullptr;

    const int threads = qBound(1, QThread::idealThreadCount() - 1, 4);
    MeltJob *job = createMeltJob(service,
                                 path,
                                 Settings.playerGPU() ? -1 : -threads,
                                 0,
                                 Settings.jobPriority(),
                                 &error);

    return JOBS.add(job);
```
